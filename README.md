# کدفا (CodeFa) — یادگیری بازی‌وار برنامه‌نویسی

کدفا یک وب‌اپ فارسی و راست‌به‌چپ برای یادگیری HTML/CSS، JavaScript و Python است. پروژه با Node.js و Express و فرانت‌اند Vanilla نوشته شده و مرحله‌ی build یا کامپایل ندارد. دیتابیس PostgreSQL است و داده‌های کاربر روی دیسک موقت ذخیره نمی‌شوند.

## امکانات

- دوره‌های مرحله‌ای HTML/CSS، JavaScript و Python مقدماتی با تمرین‌های چندگزینه‌ای، جای‌خالی، ترتیب خطوط، پیش‌بینی خروجی و کدنویسی؛ دوره‌ی HTML/CSS تمرین وب با چک‌های DOM هم دارد.
- پلی‌گراند موبایل‌فرست برای Python، JavaScript و وب؛ CodeMirror 5 از بسته‌ی npm و بدون CDN خارجی سرو می‌شود.
- ذخیره‌ی پیش‌نویس محلی، ذخیره‌ی حداکثر ۳۰ اسنیپت در حساب، لینک عمومی فقط‌خواندنی و فورک‌کردن اسنیپت.
- اجرای کد در iframe دارای `sandbox="allow-scripts"` و مبدأ opaque؛ اجرای کد کاربر روی سرور انجام نمی‌شود.
- XP، سطح، قلب، استریک، ماموریت روزانه، مرور اشتباهات، دستاوردها، هدف روزانه و پنل مدیریت.
- PWA و کش فایل‌های ثابت و دارایی‌های runtime پس از اولین دریافت؛ پاسخ‌های `/api/` در Service Worker کش نمی‌شوند.

## نیازمندی‌ها

- Node.js نسخه ۲۰ یا جدیدتر
- PostgreSQL
- npm

## اجرای پروژه

۱. مخزن را در GitHub نگه دار و آن را به Railway متصل کن.
۲. در Railway یک سرویس PostgreSQL اضافه کن.
۳. متغیرهای محیطی زیر را برای سرویس برنامه تنظیم کن:

| متغیر | توضیح |
|---|---|
| `DATABASE_URL` | آدرس اتصال PostgreSQL؛ معمولاً از متغیر اتصال سرویس PostgreSQL در Railway استفاده می‌شود. |
| `JWT_SECRET` | رشته‌ی تصادفی طولانی؛ حداقل ۳۲ نویسه. |
| `NODE_ENV` | در Railway مقدار `production` بگذار. |
| `ADMIN_USERNAME` | نام ادمین با ۳ تا ۲۰ حرف انگلیسی، عدد یا زیرخط. |
| `ADMIN_PASSWORD` | رمز قوی و یکتا با حداقل ۱۲ نویسه؛ حتماً در Railway تنظیمش کن. |

۴. برنامه با `npm install` و سپس `npm start` اجرا می‌شود. فرمان build لازم نیست.
۵. از بخش Networking دامنه‌ی عمومی Railway را بساز.
۶. آدرس `https://دامنه-تو/api/health` را باز کن؛ پاسخ سالم باید `{"ok":true,"service":"CodeFa"}` باشد.
۷. با مقادیر `ADMIN_USERNAME` و `ADMIN_PASSWORD` وارد شو و تیک آبی و پنل مدیریت را بررسی کن.

## ساخت ادمین

- ادمین فقط در صورتی ساخته می‌شود که `ADMIN_USERNAME` و `ADMIN_PASSWORD` معتبر باشند و رمز حداقل ۱۲ نویسه داشته باشد.
- اگر نام کاربری از قبل وجود داشته باشد، نقش و تیک آبی آن اصلاح می‌شود؛ رمز قبلی بازنویسی نمی‌شود.
- رمز یا نام ادمین را داخل سورس یا README قرار نده.
- نقش مدیر از دیتابیس خوانده می‌شود و APIهای `/api/admin/*` نقش را در هر درخواست بررسی می‌کنند.

## Python و Pyodide

- نسخه‌ی دقیق Pyodide در `package.json` پین شده است و فایل‌ها از `/vendor/pyodide/` سرو می‌شوند؛ CDN یا آپلود دستی runtime لازم نیست.
- Pyodide فقط وقتی صفحه‌ی پلی‌گراند یا یک تمرین Python اجرا شود بارگذاری می‌شود. بار اول دانلود runtime ممکن است به اینترنت و زمان بیشتری نیاز داشته باشد؛ پس از دریافت فایل‌ها، Service Worker می‌تواند آن‌ها را برای استفاده‌ی بعدی کش کند.
- فقط کتابخانه‌های استاندارد Python در این محیط در نظر گرفته شده‌اند. نصب بسته‌های خارجی مثل NumPy در این پلی‌گراند فعال نشده است.
- CodeMirror 5 نیز از `node_modules/codemirror` در مسیر محلی `/vendor/codemirror/` سرو می‌شود.

## امنیت اجرای کد

- JavaScript، Python و پیش‌نمایش وب در صفحه‌ی اختصاصی `/sandbox` اجرا می‌شوند که در iframe بدون `allow-same-origin` قرار می‌گیرد.
- CSP عادی سایت سخت‌گیر است؛ مجوزهای `unsafe-eval` و `wasm-unsafe-eval` فقط برای صفحه‌ی sandbox فعال‌اند تا runtime لازم بتواند اجرا شود.
- ارتباط با صفحه‌ی اصلی با `postMessage` انجام می‌شود؛ صفحه‌ی اصلی منبع پیام، مبدأ opaque و شکل پیام را بررسی می‌کند.
- محدودیت پیش‌فرض JavaScript سه ثانیه و Python هشت ثانیه است. مدیر می‌تواند مهلت را بین ۱ تا ۱۵ ثانیه تنظیم کند. در پایان مهلت، iframe بازسازی می‌شود.
- خروجی کنسول حداکثر ۱۰۰ کیلوبایت نگه داشته می‌شود.
- دسترسی شبکه داخل sandbox مسدود می‌شود؛ درخواست‌هایی مانند `fetch('/api/auth/me')` نباید بتوانند اطلاعات حساب را بخوانند. هرگز کد کاربر روی سرور اجرا نمی‌شود.
- تست‌های تمرین کدنویسی به مرورگر می‌رسند و از نظر تقلب قابل دورزدن‌اند؛ به همین دلیل XP اصلی هر درس فقط بار اول تکمیل آن داده می‌شود.
- این تمهیدات جایگزین آزمون امنیتی مستقل نیستند. قبل از عرضه‌ی عمومی، تست نفوذ و بررسی مرورگرهای هدف انجام بده.

## XP و پیشرفت

- XP اصلی بر اساس `xp_reward` درس محاسبه می‌شود و بونوس بی‌خطا از تنظیمات خوانده می‌شود؛ استفاده از راهنمایی بونوس بی‌خطا را حذف می‌کند.
- XP یک درس فقط بار اول تکمیل آن داده می‌شود؛ تلاش مجدد برای تمرین و یادگیری آزاد است.
- سطح بر اساس فرمول `floor(sqrt(XP / 100)) + 1` محاسبه می‌شود.
- قلب‌ها و استریک در سمت سرور نگهداری می‌شوند. قلب‌ها بر اساس زمان سپری‌شده بازیابی می‌شوند.
- هدف روزانه قابل انتخاب است: ۱۰، ۲۰ یا ۳۰ XP.

## PWA و اینترنت ضعیف

- `public/manifest.json` و `public/service-worker.js` برنامه را قابل نصب می‌کنند.
- فایل‌های ثابت، CodeMirror و فایل‌های Pyodide پس از اولین دریافت در Cache API ذخیره می‌شوند.
- درخواست‌های `/api/` عمداً در Service Worker کش نمی‌شوند؛ بنابراین حالت آفلاین شامل عملیات حساب و ذخیره‌ی دائمی نیست.
- آیکون برنامه SVG است؛ اگر مرورگر یا فروشگاهی PNG بخواهد، برای آن خروجی PNG جداگانه تهیه کن.

## فونت Vazirmatn (اختیاری)

رابط با فونت‌های سیستمی هم کار می‌کند. اگر خواستی فونت محلی داشته باشی، فایل‌های `Vazirmatn-Regular.woff2` و `Vazirmatn-Bold.woff2` را از مخزن رسمی Vazirmatn دریافت و در `public/fonts/` قرار بده. هیچ فونتی از CDN بارگذاری نمی‌شود.

## مسیرهای اصلی

- `GET /api/health` — سلامت سرویس
- `GET /api/courses` و `GET /api/courses/:slug` — مسیر دوره‌ها
- `GET /api/lessons/:id`, `POST /api/lessons/:id/answer`, `POST /api/lessons/:id/complete` — درس و پیشرفت
- `GET/POST /api/playground/snippets` — اسنیپت‌های حساب
- `GET /api/playground/shared/:shortId` — اسنیپت عمومی
- `GET /api/achievements`, `GET /api/quests/today`, `GET /api/mistakes` — دستاورد، ماموریت و مرور
- `GET /api/admin/playground` — مدیریت اسنیپت‌ها (ادمین)

## تست و محدودیت‌ها

- بررسی نحوی JavaScript با parser جاوااسکریپت و اعتبارسنجی JSON درس‌ها در این محیط انجام شده است؛ این بررسی به معنی اجرای end-to-end نیست.
- اتصال زنده به PostgreSQL، دانلود کامل runtime از npm، اجرای واقعی مرورگر و دیپلوی Railway در این محیط تأیید نشده‌اند.
- پس از اولین دیپلوی، حتماً `/api/health`، ثبت‌نام/ورود، ساخت ادمین، اجرای کد در هر سه حالت، قطع حلقه‌ی بی‌نهایت، دسترسی iframe به API، ذخیره/اشتراک‌گذاری/فورک و عملیات CMS را روی یک دیتابیس آزمایشی تست کن.
