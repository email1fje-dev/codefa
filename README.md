# CodeFa | یادگیری برنامه‌نویسی، قدم‌به‌قدم

CodeFa یک وب‌اپ فارسی و راست‌به‌چپ برای یادگیری HTML، CSS و JavaScript با مسیر مرحله‌ای، تمرین‌های تعاملی، قلب، XP، استریک و پنل مدیریت است. رابط با HTML/CSS/JavaScript ساده ساخته شده و نیازی به مرحله build ندارد.

## نیازمندی‌ها
- Node.js نسخه ۲۰ یا بالاتر
- PostgreSQL
- متغیرهای محیطی `DATABASE_URL` و `JWT_SECRET`؛ برای ساخت ادمین `ADMIN_USERNAME` و `ADMIN_PASSWORD` نیز تنظیم شوند.

## راه‌اندازی با گوشی و Railway
۱. در GitHub یک مخزن با نام دلخواه بساز.
۲. فایل‌های پروژه را با گزینه Upload files در GitHub آپلود کن و پوشه‌ها را حفظ کن.
۳. در Railway گزینه New Project و سپس Deploy from GitHub Repo را انتخاب کن و مخزن را وصل کن.
۴. در همان پروژه یک سرویس PostgreSQL اضافه کن. مقدار اتصال آن را در متغیر `DATABASE_URL` سرویس CodeFa قرار بده.
۵. در Variables سرویس CodeFa این متغیرها را تنظیم کن:
   - `NODE_ENV=production`
   - `JWT_SECRET`: رشته تصادفی طولانی، حداقل ۳۲ کاراکتر
   - `ADMIN_USERNAME`: نام کاربری ۳ تا ۲۰ کاراکتری شامل حروف انگلیسی، عدد یا زیرخط
   - `ADMIN_PASSWORD`: **حتماً در Railway مقدار قوی بگذار**؛ حداقل ۱۲ کاراکتر. این رمز در کد یا README قرار نمی‌گیرد.
   - `DATABASE_URL`: آدرس اتصال PostgreSQL
۶. Railway با Nixpacks و دستور `npm start` سرویس را اجرا می‌کند؛ نیازی به Dockerfile یا build فرانت‌اند نیست.
۷. از بخش Settings گزینه Generate Domain را بزن. مسیر `/api/health` باید JSON با `ok: true` برگرداند.
۸. با نام کاربری و رمزی که خودت در Variables گذاشتی وارد شو؛ کنار حساب ادمین تیک آبی نمایش داده می‌شود و مسیر `/admin.html` پنل را باز می‌کند.

## فونت فارسی (اختیاری)
برای استفاده از فونت محلی Vazirmatn، نسخه‌های `Vazirmatn-Regular.woff2` و `Vazirmatn-Bold.woff2` را از مخزن رسمی Vazirmatn دریافت و در `public/fonts/` قرار بده. بدون این دو فایل، رابط با Tahoma و فونت‌های سیستم هم کار می‌کند. هیچ CDN خارجی لازم نیست.

## درس‌ها و داده‌ها
در شروع سرویس، `db/schema.sql` اجرا می‌شود و تنظیمات پیش‌فرض را بدون بازنویسی تنظیمات موجود اضافه می‌کند. فایل‌های JSON درس‌ها فقط وقتی جدول courses خالی است وارد PostgreSQL می‌شوند؛ پس از ایمپورت، محتوای درس از دیتابیس خوانده می‌شود و ویرایش‌های CMS با deploy بعدی از بین نمی‌روند.

## منطق امتیاز و پیشرفت
- XP درس فقط بار اول تکمیل به کاربر داده می‌شود؛ تکمیل مجدد، XP دوباره نمی‌دهد. درس بی‌خطا بونوس تنظیم‌پذیر دارد.
- سطح با فرمول `floor(sqrt(XP / 100)) + 1` محاسبه می‌شود.
- هر پاسخ نادرست یک قلب کم می‌کند؛ بازیابی قلب در سمت سرور بر اساس دقیقه‌ی تنظیم‌شده محاسبه می‌شود.
- استریک با تاریخ فعالیت روزانه افزایش می‌یابد و پس از جا افتادن یک روز، فعالیت بعدی آن را از یک شروع می‌کند.
- رتبه‌بندی هفتگی از جمع رکوردهای XP در هفته جاری و رتبه‌بندی کلی از XP فعلی استفاده می‌کند.

## امنیت
- رمزها با bcryptjs و هزینه ۱۲ هش می‌شوند. JWT در کوکی HttpOnly و SameSite=Lax نگهداری می‌شود.
- نقش ادمین برای هر درخواست مدیریتی از دیتابیس خوانده می‌شود. ثبت‌نام نمی‌تواند نقش یا تیک تأیید را تعیین کند.
- تغییرات پنل به `X-Requested-With: CodeFa` نیاز دارند، محدودیت نرخ جداگانه دارند و در audit_log ثبت می‌شوند.
- کد تمرین در سرور اجرا نمی‌شود؛ اجرای JavaScript در مرورگر و Worker با محدودیت زمان انجام می‌شود.
- تیک آبی صرفاً نشان اعتبار نمایشی است و دسترسی مدیریتی ایجاد نمی‌کند.

## نقشه راه
پشتیبانی از Python می‌تواند در نسخه‌های آینده اضافه شود. در این نسخه فقط HTML/CSS و JavaScript ارائه شده‌اند.
