# کدفا (CodeFa)

وب‌اپ فارسی و راست‌به‌چپ برای یادگیری مقدماتی HTML، CSS و JavaScript با درس‌های کوتاه، تمرین‌ها، XP، استریک، رتبه‌بندی و پنل مدیریت.

## نیازمندی‌ها
- Node.js نسخه ۲۰ یا جدیدتر
- PostgreSQL (در Railway سرویس PostgreSQL بسازید)
- بدون build step؛ فرانت‌اند HTML/CSS/JavaScript ساده است.

## راه‌اندازی با گوشی و GitHub
۱. ریپو را در GitHub باز کنید و مطمئن شوید فایل‌های پروژه روی شاخه `main` هستند.  
۲. در Railway یک پروژه بسازید و گزینه Deploy from GitHub Repo را انتخاب کنید؛ ریپوی `email1fje-dev/codefa` را وصل کنید.  
۳. از داخل همان پروژه، سرویس PostgreSQL اضافه کنید.  
۴. در Variables سرویس اپ این متغیرها را تنظیم کنید:
   - `DATABASE_URL`: آدرس اتصال PostgreSQL از سرویس دیتابیس Railway
   - `JWT_SECRET`: رشته تصادفی طولانی، حداقل ۳۲ نویسه
   - `NODE_ENV=production`
   - `ADMIN_USERNAME`: نام ادمین با ۳ تا ۲۰ حرف انگلیسی، عدد یا زیرخط
   - `ADMIN_PASSWORD`: رمز قوی با حداقل ۱۲ نویسه؛ حتماً رمز واقعی و منحصربه‌فرد بگذارید.
۵. Deploy را اجرا کنید. برنامه در هر استارت schema را idempotent اجرا می‌کند و اگر جدول courses خالی باشد درس‌های JSON را وارد دیتابیس می‌کند.  
۶. در تنظیمات Networking گزینه Generate Domain را بزنید.  
۷. آدرس `https://دامنه-شما/api/health` را باز کنید؛ باید JSON با `ok: true` ببینید.  
۸. با `ADMIN_USERNAME` و `ADMIN_PASSWORD` وارد شوید و پنل مدیریت را بررسی کنید.

## نکات امنیتی
- هرگز فایل `.env` یا مقادیر واقعی متغیرها را در GitHub قرار ندهید.
- رمز ادمین اگر کمتر از ۱۲ نویسه باشد، اکانت ادمین در راه‌اندازی اولیه ساخته نمی‌شود.
- اگر نام ادمین از قبل وجود داشته باشد، نقش و تیک آبی آن اصلاح می‌شود ولی رمز موجود بازنویسی نمی‌شود.
- JWT در کوکی HttpOnly با SameSite=Lax و در production با Secure ذخیره می‌شود.
- APIهای مدیریتی نقش را مستقیماً از دیتابیس می‌خوانند؛ درخواست‌های تغییردهنده به هدر `X-Requested-With: CodeFa` نیاز دارند.
- کد تمرین در مرورگر اجرا می‌شود، نه روی سرور. داده‌های دیتابیس روی PostgreSQL نگهداری می‌شوند و به دیسک موقت Railway وابسته نیستند.

## منطق XP و سطح
تکمیل بار اول هر درس XP تعریف‌شده برای درس و ۵ XP بونوس برای امتیاز کامل می‌دهد؛ تکرار درس XP دوباره نمی‌دهد. سطح با فرمول `floor(sqrt(XP / 100)) + 1` محاسبه می‌شود. قلب‌ها در دیتابیس نگهداری و بر اساس زمان سپری‌شده بازیابی می‌شوند. استریک با تاریخ محلی تهران به‌روزرسانی می‌شود.

## فونت اختیاری
پروژه با فونت‌های سیستمی هم کار می‌کند. برای افزودن Vazirmatn، فایل‌های `Vazirmatn-Regular.woff2` و `Vazirmatn-Bold.woff2` را از مخزن رسمی Vazirmatn دریافت و در `public/fonts/` قرار دهید.

## نقشه راه
- افزودن دوره Python در نسخه آینده؛ این نسخه فقط روی HTML/CSS و JavaScript مقدماتی تمرکز دارد.

## وضعیت تست
فایل‌ها از طریق GitHub API ثبت شده‌اند؛ در این محیط اجرای واقعی `npm install`، تست اتصال PostgreSQL و دیپلوی Railway انجام نشده است. پیش از استفاده عمومی، مسیرهای اصلی را روی دیتابیس آزمایشی بررسی کنید.
